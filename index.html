QUASAR
Military Object Detection & Classification

Object detection pipeline for military assets in SAR and EO imagery. Gen-1 covers 5 broad classes; Gen-2 expands to 16 subclasses using a MIM (Masked Image Modeling) backbone for richer feature representation.

Object Detection SAR/EO 16 Classes MIM Backbone
Gen-1 → Gen-2
HARMONY
EO/SAR Auto-Registration

Automated co-registration of electro-optical and SAR imagery. Gen-1 achieves fine co-registration below 100m offset; Gen-2 tackles coarse co-registration, reducing 500m displacement to ~50m through learned feature alignment.

Image Registration EO/SAR Fusion <100m Error
Gen-1 Deployed · Gen-2 R&D
CHRONOS
Change Detection & Segmentation

Temporal change segmentation maps from multi-date SAR and EO imagery at 0.3m–2m GSD. Gen-1 uses statistical methods; Gen-2 brings AI-based detection for improved sensitivity and fewer false positives.

Change Detection Segmentation 0.3m–2m GSD AI-Based
Active Development
S2O
SAR-to-Optical Translation

Translates synthetic aperture radar imagery to photorealistic optical output. Regenerates PAN images from SAR at 0.3m–2m resolution, enabling human-interpretable radar visualization without requiring optical sensors.

Image Translation Generative AI SAR → Optical 0.3m GSD
R&D Phase
SARSIMX
SAR Simulator from 3D CAD

Generates synthetic SAR imagery from 3D CAD models using the RaySAR ray-tracing framework. Enables sim-to-real training data generation without physical sensors — critical for rare target augmentation.

SAR Simulation RaySAR 3D CAD → SAR
